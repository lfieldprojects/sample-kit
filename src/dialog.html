SampleKit

Export arrangement segments between locators as device-ready WAV files.

Preparing your set

Sample Kit exports audio between locators as WAV files.

  • Arrangement View
  • Audio tracks only
  • 2+ locators, including an end locator
  • A saved set (for project exports)

Option 1 — Quick export

Does not include sends or master.

  1. Duplicate tracks or groups to export
  2. Add locators (+ end locator after the last section)
  3. Bounce duplicates in place
  4. Right-click each bounced track → Export Locator Samples…
  5. Choose preset and export

Option 2 — With sends & master

Stem first, then export. Use when you want return and master in the sound.

  1. Export stems as you normally would
  2. New Live set → add stems to Arrangement
  3. Add locators (+ end locator)
  4. Bounce in place if needed
  5. Right-click each track → Export Locator Samples…
  6. Choose preset and export

Good to know

  • Exports use pre-FX audio (track devices are not included).
  • MIDI tracks must be frozen or flattened to audio before export.
  • Save your Live Set first. Project exports usually land in Samples/Imported/.
